# Observer — сборки

Observer — пошаговая игра о главе экспедиций Службы дальнего наблюдения: карта системы, Чужие,
Кодекс невмешательства, гонка за Оружием Ушедших. Здесь лежат только готовые сборки прототипа,
исходники — в отдельном репозитории.

**Скачать:** [Releases](https://github.com/NektoDron/Observer-builds/releases/latest)

| Платформа | Архив | Запуск |
|---|---|---|
| Windows x64 | `Observer-windows-x64.zip` | распаковать, `Observer.exe` |
| Linux x64 | `Observer-linux-x64.zip` | распаковать, `./Observer.x86_64` (при необходимости `chmod +x`) |
| macOS (Intel и Apple Silicon) | `Observer-macos.zip` | распаковать, `Observer.app`; сборка без подписи Apple — при первом запуске правая кнопка → «Открыть» |

Игра при запуске проверяет новые версии и предлагает обновиться из меню (Esc) без переустановки.
Сохранения и журнал обновления — в папке профиля: `%APPDATA%\Godot\app_userdata\Observer`
(Windows), `~/.local/share/godot/app_userdata/Observer` (Linux),
`~/Library/Application Support/Godot/app_userdata/Observer` (macOS).
